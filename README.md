# dev-log

Session records of the Operations Orchestra: what each person decided while working with an AI
assistant, what the assistant decided, and what is still open. One folder per member, one file
per session, named `YYYY-MM-DD-topic.md`.

Moved here from `example-device/sessions/` (branch `prototype/synthetic-record`) on 19 November
2026, so that records about any repository of the organization live in one place.
